# 🍎 Fruit Recognition (TensorFlow)

## 🔍 What is this?
An image classification project that identifies different fruits using a **TensorFlow-based Neural Network**.

---

## 💡 Key Idea
Train a model on fruit images so it can **predict the correct fruit label** from new unseen images.

---

## 🧩 Input → Output
- **Input:** Fruit image  
- **Output:** Predicted fruit category  

---

## 🏗️ Model Details
- Built using TensorFlow / Keras  
- Uses a **CNN (Convolutional Neural Network)**  
- Learns patterns like color, texture, and shape  

---

## ⚡ Steps Involved
1. Load & preprocess images  
2. Train CNN model  
3. Validate performance  
4. Make predictions  

---

## 🛠️ Tools Used
- Python  
- TensorFlow / Keras  
- NumPy
